# UART Receiver (SystemVerilog)

A fully integrated UART Receiver supporting configurable parity and prescaling.

## Features
- **Configurable Data Width:** Supports 5 to 8-bit data.
- **Error Detection:** Built-in Start-bit glitch, Parity, and Framing error checking.
- **Hierarchical Simulation:** Professional Tcl environment for Questa/ModelSim.

## How to Run
1. Open QuestaSim.
2. In the console, type: `do run.do`
